# 감염병 데이터 탐험실 2.0
기획·제작: 백기진 | 기존 공개수업 지도안: 허선옥·백기진 | 개발보조: OpenAI ChatGPT

## 설치/실행
GitHub Codespaces의 현재 Python 환경에서 다음 명령을 사용합니다. 가상환경을 새로 만들지 않습니다.
```bash
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```
`streamlit_app.py`는 학습 목표 및 데이터 설명만 담고, `pages/1_데이터_시각화.py`에 CSV 업로드와 Plotly 기술통계를 구현하여 교수님 10쪽 실습 조건을 충족합니다. 나머지 페이지에 교육용 외삽, 퀴즈, 학습 기록을 추가했습니다.

## 업로드 CSV 규격
필수: `연도, 감염병, 발생건수`에 해당하는 열. 선택: `국가, 급수`. 앱에서 원본 열 이름에 맞게 지정. UTF-8-SIG 또는 CP949 권장. 단위·통계 정의가 다르면 서로 비교하지 말 것. 실제 공공기관 CSV를 제공받지 못해 임의의 감염병 수치를 예제 데이터로 포장하지 않았습니다.

## 데이터 출처
질병관리청 감염병포털 https://dportal.kdca.go.kr/ ; WHO Global Health Observatory https://www.who.int/data/gho ; 공공데이터포털 https://www.data.go.kr/
데이터명, 원 URL, 다운받은 날짜, 단위, 감시유형, 국가/지역, 관측기간을 필수로 기록하고 제출 전 교사가 검증합니다. 공공 데이터 라이선스 및 출처 표기 지침을 준수합니다.

## 시연 제한과 보안
학생 `로그인`은 가명 코드로 활동을 구분하는 데모일 뿐 본인 인증이 아닙니다. 교사 PIN은 환경변수 `TEACHER_PIN` 또는 Streamlit secrets로 설정(설정 없으면 교사 모드 비활성화). 여러 사용자의 중복 가명 사용을 방지하지 못합니다. SQLite DB는 `/tmp`에 저장되어 배포 환경에서 재기동 때 사라질 수 있고 서버 인스턴스 간 공유되지 않습니다. **실제 학생을 대상으로 공개 배포할 때는 학교 승인 인증, 역할별 접근제어, 관리형 DB, 보존기간, 개인정보영향 검토 등이 선행되어야 합니다.**
AI 튜터는 `OPENAI_API_KEY` 환경변수/secrets가 있어야만 외부 호출합니다. 미설정 시 자기점검 지침을 표시합니다. 개인식별정보 입력 금지. AI 응답은 교사가 검토합니다.

## 예측 교육 주의
관측값을 최근값 유지 또는 선형 외삽으로 연장하는 **수업용 시나리오**만 제공하며, 신종 감염병 발생 예측·공식 방역 예보·정확도 검증된 예측 모델이 아닙니다. 급수는 병원체 위험도 랭킹이 아니며 법정 분류가 역사적으로 바뀌므로 당시 기준 확인이 필요합니다.
